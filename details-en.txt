quirky text parser;
description v.2025-10;

About:
1-file javascript wrapper intended/able to:
- open multiple text/binary files at once;
- identify, parse, sort, filter, translate, tts text;
- identify, parse, sort, filter, play, view binaries;
- export text (images as base64) to html;
- ability to adopt more browser features.

Main steps:
- Check bubbles UI "Options", or the same section inside quirky's html itself;
- Choose input files with folder UI "Open"; it can be a set of news feeds, images, audio, video; bytes load should be less than available userspace device memory; and there is max size per file limit defined in fread();
- On success you can at least save text you see to file; see "Gestures" section inside quirky file;

Text-to-speech is a browser offline feature;
Text translation is an online web-service of a pretty well-known provider;

If one will choose bilingual translation (tran+orig options) then it will be shown on translated text single touch.

If something will go wrong, there surely are these main errors:
- quirky bugs itself (absent browser's features checks, non-strict property declarations, so on);
- non-standart input data (like absent/unqualified date format in xml news feed file);
- browser restrictions and system limitations (like exceeded memory);
- quirky version is too old and it's wrapping methods are obsolete;
- unique, previously unknown, fresh and bright error.

Disvantages:
Eclectic, non-convient formatted, monolytic, depending on different browser's implementations, optionally requires additional software like Total Commander for Android or Termux to work with;

Advantages:
Essential code fits on smartphone screen in text editor, running on modern browsers, on most mobile platforms, simple upgrade, less scrolling, avoiding malformed content which can be met in a wild;

Some actual features:
1) Get manually different news pages, news feeds, images, audio, video as files; for ex., with left swipe and long press "Save/download as" popup Chromium/Chrome/Firefox option;
2) Open them multiple at once;
3) View them reformed, sorted by date of post
3a) filtered: check Filters sect. inside;
3b) and decorated: check Options sect. inside;
4) Translate them on fly;
5) Listen them voice-over with one touch;
6) Zoom them with double touch;
7) Save them with right swipe gesture;
7a) Save them with images inlined;
8) Resort them by tags with left swipe gesture;
9) Analyse FFT input/file audio data;
10) Deploy any related tasks like search strings in vocabulary text files by input, 2d board simulation, so on;
