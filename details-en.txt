quirky text parser
User Manual v.2025-10;

Topic, subject:
Minimalistic wrapping core around user tasks, opened with browser by, for ex., long press and "Open with" pop-up.

Disvantages:
Eclectic, non-convient formatted, monolytic, parenting by browser's implementations and restrictions, optionally requires 3-rd party software like Total Commander for Android or Termux

Advantages:
Essential code fits smartphone screen with any text editor, running on any modern browser, on any compatible mobile platform, has relatively easy debug/upgrade, short scrolling, avoiding rogue malware which can be exist in ads, images, active content, or even in text on server's responces..

Some actual features:
1) Get manually different news pages, news feeds, images, audio, video as files; for ex., with left swipe and long press "Save/download as" popup Chromium/Chrome/Firefox option;
2) Open them multiple;
3) View them at once, sorted by date of post
3a) filtered: check Filters sect. inside;
3b) and decorated: check Options sect. inside;
4) Translate them on fly with option activated;
5) Listen them with one touch tts voice-over;
6) Zoom them with double touch;
7) Save them with right swipe gesture;
7a) Save them with images inlined;
8) Resort them by tags with left swipe gesture;
9) Analyse FFT audio data from input or file;
10) Deploy any related tasks like search strings in vocabulary text files by input, 2d board simulation, so on;
