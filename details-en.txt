User Manual v.2025-10;

Topic, subject:
Light wrapping core around user tasks, opened with browser by, for ex., long press and "Open with" pop-up.

Disvantages:
Eclectic, non-convient formatted, monolytic, parenting with browser's implementations and restrictions, optionally requires additional software like Total Commander for Android or Termux to work with;

Advantages:
Essential code fits on smartphone screen in any text editor, running on any modern browser, on most mobile platforms, simple upgrade, short scrolling, avoiding rogue malformed content which can be meet in ads, images, acripts or, even, in text like stylesheets within server's or mitm responses..

Some actual features:
1) Get manually different news pages, news feeds, images, audio, video as files; for ex., with left swipe and long press "Save/download as" popup Chromium/Chrome/Firefox option;
2) Open them multiple at once;
3) View them reformed, sorted by date of post
3a) filtered: check Filters sect. inside;
3b) and decorated: check Options sect. inside;
4) Translate them on fly;
5) Listen them voice-over with one touch;
6) Zoom them with double touch;
7) Save them with right swipe gesture;
7a) Save them with images inlined;
8) Reform them by tags with left swipe gesture;
9) Analyse FFT audio data from input or file;
10) Deploy any related tasks like search strings in vocabulary text files by input, 2d board simulation, so on;
